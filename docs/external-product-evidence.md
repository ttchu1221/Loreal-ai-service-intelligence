# 外部产品信息与推荐边界

## 当前已核验来源

截至 2026-10-01，巴黎欧莱雅中国官网首页的“大家都在搜”公开展示了“黑精华第四代、全新复颜
水乳、小蜜罐、胶原水乳、安瓶面膜、紫熨斗、防晒、复颜提拉面膜、20霜”等搜索候选：

- 来源：<https://www.lorealparis.com.cn/>
- 市场：中国大陆；
- 可支持事实：这些名称出现在官网热门搜索区域；
- 不可推出事实：具体销量名次、库存、价格、具体 SKU 功效或对某个消费者的适配结论。

当前 demo 只选取其中有明确产品指向的护肤候选用于通用推荐回答。官网中的“防晒、面膜、面霜”等
品类词不作为具体产品推荐。搜索结果只能称为“官网热门搜索候选”，不得改写为“销量第一”“全网
爆款”或“人人适用”。

中国官网的[印迹系列页面](https://www.lorealparis.com.cn/lip-makeup/rouge-signature)还展示了
“印迹唇釉-柔雾小钢笔 129”“欧莱雅印迹唇釉 129（水光）”和“印迹唇釉-初吻小钢笔 129”。
这些产品可以作为唇妆类候选，但该页面不是销量榜单，因此不得称为“热门销量款”。页面公开描述只
支持对应款式、妆效和质地字段；不能由此推断适合某种肤色、适合唇纹深的人群或“绝对不拔干”。

巴黎欧莱雅的[官方口红使用与选色指南](https://www.lorealparisusa.com/beauty-magazine/makeup/lip-makeup/how-to-apply-lipstick)
区分肤色明暗与 undertone，并给出“暖 undertone 优先尝试暖调唇色、冷 undertone 优先尝试冷调
唇色”的一般选色方向。该页面来自美国市场，可用于不涉及 SKU 的通用色彩原则，不得用于证明中国
大陆某个具体色号的名称、配方、库存或适配结果。

中文美妆语境里的“黄二白”通常表示“黄调 + 第二档白度”，但它不是跨品牌统一的标准色阶，且属于
消费者自述。系统可以把它作为暖调方向的弱信号，再结合期望风格、原生唇色和自然光试色缩小范围；
不得仅凭这一标签承诺“显白”或个人适配。对“赤茶红 / 枫叶红”这类名称，若没有对应系列商品页，
只能按名称表达的色彩方向给出有条件的试色顺序，必须明确不是具体 SKU 的官方结论。

上述官方文章已整理为随 application package 发布的中文结构化知识卡
`providers/data/lipstick_selection_guide_zh.json`。知识卡只保存中文摘要、原子知识点、回答规则、
禁止推断项和来源 metadata，不保存或逐字翻译官网全文。Runtime 的 `KB-SHADE-001` 会读取该卡片，
因此类似肤色、undertone、妆效和口红二选一问题可以复用同一份已审计知识。

`KB-SHADE-001` 当前另附一张用户提供的临时选色参考图，metadata 记录在知识卡的
`supporting_media` 中，原图保存为 `providers/data/kb-shade-001-reference.jpg`。该图在消费者端作为
可点击缩略图展示，并明确标记 `pending` 和“来源待审核”。是否附图由回复生成 provider 根据当前
问题、对话上下文和图片语义选择，不因命中 `KB-SHADE-001` 而固定展示；backend 会校验选择结果必须
属于本轮已检索 evidence，provider 失败时则不附图。它不是巴黎欧莱雅官方资料，也不能作为
具体色号、SKU、显白效果或个人适配结论的依据。拿到正式审核图片后可直接替换文件并同步更新
`source_type`、`review_status`、usage boundary 和版本记录。

## 推荐规则

1. 优先匹配中国大陆官方来源；其他国家或地区官网只能作为对应市场资料，不得冒充中国大陆 SKU。
2. 候选产品名称、功效、质地、成分、色号和使用方法分别核验，不因名称相似跨产品借用。
3. 官网热门程度只参与候选排序，不作为功效 evidence。
4. 推荐回答必须使用消费者在当前或历史对话中明确给出的条件匹配候选，并解释匹配维度；条件不足时
   只确认一个可由现有 evidence 区分的关键维度，不得默认推荐候选列表中的第一项。无法确认具体
   商品时，不输出绝对适配或效果承诺。
5. 来源失效、商品下架或资料发生变化后，该条 knowledge 必须降级，不再参与自动回复。

## 当前缺口

当前官网 evidence 只覆盖印迹系列页面展示的 129 款式，尚不能把案例中的 `#01 赤茶红`、`#05
枫叶红` 映射到具体系列或 SKU，也不能支持这两个色号的肤色适配和拔干判断。系统不会使用法国、
英国、香港或台湾官网资料替代中国大陆 SKU；要补足该案例，仍需中国大陆官方商品链接或审核后的
商品知识卡。
